# TeamSelector
Плагин для сервера Mindustry (ultra optimized)

Отполирован код, при входе моментально игрок не спавнится а находится в спектаторе.
Так же покажет меню выбора команды, запоминает при перезаходе на сервер, сменить команду уже можно через /ct (change team).
Ник игрока меняется на логотип команды, цвет команды.
работает асинхронно, на мобильниках тоже проверено, отлично синхронизируется.

Протестировано на сервере с 1 ядром и 500 мб оперативки, сервер потреблял не более 30 мб (карты, игроки + плагин).

Компилируйте сами, моментально компилируется: `gradle clean jar` или ждите обновления раз в месяц :(
