## TeamSelector — кратко о проделанной работе

### Что делает
**Меню выбора команды** — Sharded / Crux / «Наблюдать» при входе на карту и после каждой смены карты, на новом UI-билдере v8 (160+).

**Цветной тег в нике** — значок * в цвете фракции; ник и его собственный цвет игрока не трогаются, наблюдатели — серые.

**Зритель по умолчанию** — вход даёт дереликта, камеру в центр; ESC/BACK/«Наблюдать» оставляют смотреть.

**Клик = честный респавн** — юнит снимается, ваниль сама спавнит у ядра; камера сервером наводится на юнита (работает и на Android).

**Админ-совместимость** — смена команды из панели убивает юнита до применения; посторонние команды (malis и т.п.) безопасно превращают игрока в зрителя.

### Чем лучше типичных плагинов с GitHub
**Современный API** — registerMenuBuilder/UI-дерево вместо легаси Call.menu, как у большинства существующих.

**Не дублирует игру** — спавн и логика команд ванильные, плагин только управляет; не сломается с обновлениями.

**Событийность, ноль таймеров** — нет типичного для гитхаба опросника Timer.schedule каждую секунду; код работает только по событиям.

**Безопасность по стектрейсам** — NPE, AIOOBE, подделка тега, инъекции кликов: каждый вектор закрыт и обоснован реальным крашем или grep'ом, а не «на всякий случай».

**Производительность и память** — идемпотентные вызовы (ноль аллокаций на респавнах), stateless, ничего не удерживает игроков, утечки исключены.

**Минимальный размер** — ~15 строк логики, ~2 КБ jar; читается за минуту, ноль зависимостей — легко аудировать и форкать.

**Проверено боем** — все сценарии прогнаны на живом сервере, включая Android и краш-кейсы; каждый фикс — по стектрейсу.

**Выпаренный код** — от ~50 строк исходника с таймерами и регэкспами до чистого ядра за 20 итераций ревизий; ни одной лишней строки.
